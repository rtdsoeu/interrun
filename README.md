# InterRun

> **Multimodal Endless Runner with Adaptive Intelligent Control**  
> Three.js + Google MediaPipe + Web Audio API + Vite

[![Deploy to GitHub Pages](https://github.com/rtdsoeu/interrun/actions/workflows/deploy.yml/badge.svg)](https://github.com/rtdsoeu/interrun/actions/workflows/deploy.yml)
[![Demo](https://img.shields.io/badge/Demo-GitHub%20Pages-blue)](https://rtdsoeu.github.io/interrun/)

**InterRun** - безбар'єрна браузерна відеогра жанру Endless Runner з адаптивною системою мультимодального керування на основі комп'ютерного зору (MediaPipe FaceLandmarker та HandLandmarker у Web Worker), що функціонує безпосередньо у вікні веббраузера без встановлення додаткового програмного забезпечення чи плагінів.

## Основні архітектурні особливості

1. **Двопотокова клієнтська архітектура (Dual-Loop Web Worker):** рендеринг Three.js стабільно утримує 60 FPS, а обробка кадрів комп'ютерного зору виконується у фоновому потоці Web Worker із нульовим копіюванням пам'яті через об'єкти `ImageBitmap` (Transferable).
2. **Просторовий автокалібратор пози (`AdaptivePoseCalibrator`):** одноразове стартове калібрування за 15 кадрами (~0,5 с), фіксований центр $X = 0{,}50$ та асиметричний динамічний захист нижньої межі кадру (Footroom Margin), що усуває зриви відстеження при нахилі кришки ноутбука.
3. **Динамічне регулювання складності (TTC DDA):** зміна темпу гри та щільності бар'єрів за метрикою Time-To-Collision із 8-секундним захисним періодом відновлення (Grace Period) після аварій та нагородженням ризикових ухилень (Near-Miss, +150 бонусних очок).
4. **Конфіденційність за замовчуванням (Privacy by Design):** 100 % обробки відео виконується локально на пристрої користувача без передачі кадрів у мережу.

## Шість етапів мультимодального керування

| Етап | Дистанція | Спосіб введення | Опис механіки |
| :---: | :---: | :--- | :--- |
| **0** | 0-300 м | Клавіатура / D-pad | Стрілки клавіатури або `WASD` на ПК; віртуальний D-pad на смартфонах |
| **1** | 300-650 м | Свайпи мишею / пальцем | Горизонтальні та вертикальні свайпи мишею або пальцем по екрану |
| **2** | 650-950 м | Положення голови (сітка 3×3) | Відстеження кінчика носа (`landmark[1]`): нахили голови ліворуч/праворуч, стрибок вгору, підкат вниз |
| **3** | 950-1250 м | Положення долоні (сітка 3×3) | Переміщення відкритої кисті у звуженій ергономічній зоні (16 % ширини кадру) |
| **4** | 1250-1850 м | Жести пальців | 1 палець - ліва смуга; 2 пальці - центр; 3 пальці - права смуга; долоня - стрибок; кулак - підкат |
| **5** | 1850-2250 м | Помахи кистю в повітрі | Швидкі змахи кисті в повітрі з блокуванням зворотного відкату Anti-Recoil (400 мс) |
| **0+** | понад 2250 м | Клавіатура (новий цикл) | Зациклення на етап 0 із приростом швидкості `+2,0 м/с` на кожному колі |

Між етапами передбачено 3,5-секундний безпечний коридор переходу без перешкод із тимчасовим сповільненням до 10,5 м/с та достроковим прогрівом нейромереж.

## Системні вимоги

- **Браузер:** Google Chrome 115+, Microsoft Edge 115+, Mozilla Firefox 120+, Apple Safari 17+ (із підтримкою WebGL 2.0, WebAssembly SIMD, Web Workers, `getUserMedia`).
- **Обладнання:** стандартна вебкамера (від 640×480 при 15-30 FPS); клавіатура або сенсорний екран.
- **ОС:** Windows 10/11, macOS, Linux, Android, iOS.

## Швидкий старт для розробників

### 1. Передумови
Встановіть [Node.js](https://nodejs.org/) (версія 18 LTS або 20 LTS) та npm:
```bash
node -v
npm -v
```

### 2. Клонування та встановлення залежностей
```bash
git clone https://github.com/rtdsoeu/interrun.git
cd interrun
npm install
```

### 3. Запуск локального сервера розробки (Vite)
```bash
npm run dev
```
Відкрийте `http://localhost:5173/` у браузері.

### 4. Запуск для мобільних пристроїв у локальній мережі (HTTPS)
```bash
npm run host
```
Дозволяє відкрити гру на смартфоні через Wi-Fi з підтримкою вебкамери через автоматичний локальний SSL-сертифікат.

### 5. Автоматизоване тестування
```bash
npm test
```

### 6. Збирання для продакшну
```bash
npm run build
```
Скомпільований оптимізований бандл зберігається у каталозі `dist/`.

## Гарячі клавіші

- `C` - примусове автокалібрування нейтральної пози обличчя чи руки;
- `M` - увімкнення / вимкнення звукових ефектів та фонової музики;
- `P` / `Escape` - пауза гри;
- `Space` - рестарт після аварії;
- `G` - режим інспекції (безсмертя персонажа);
- `1`..`6` - перемикання етапів керування у режимі налагодження.

## Структура вихідного коду

```
interrun/
├── .github/workflows/     # CI/CD конвеєр GitHub Actions (автозбірка, тести, деплой)
├── public/                # Статичні ресурси, моделі MediaPipe (.task), аудіо
├── src/
│   ├── analytics/         # Модулі телеметрії, розрахунку TTC, опитування SUS
│   ├── audio/             # Процедурний Web Audio синтезатор та плеєр BGM
│   ├── controls/          # Контролери введення етапів 0-5 (BaseControl, Strategy)
│   ├── game/              # Ядро гри Three.js (Engine, Runner, ObstacleManager, Track)
│   ├── i18n/              # Локалізація (українська / англійська)
│   ├── ui/                # Модульний інтерфейс користувача (HUD, модальні вікна)
│   └── vision/            # Web Worker, автокалібратор, фільтр 1-Euro, аналізатори
├── tests/                 # Автоматизовані модульні та інтеграційні тести
```
